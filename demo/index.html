dsh-webmcp demo agent-ready

This page exposes real WebMCP tools to browsing agents (via the in-page sitekit snippet + a declarative form). Discover it with dsh-webmcp-serve --check https://t-markus-liang.github.io/dsh-webmcp/demo/ or webmcp_discover(url) in a dsh session.

Declarative form tool

registers a submit_contact_request (destructiveHint) tool — the simplest way to expose a real action.

JS-registered read-only tool

Open the console, or connect an agent, and call get_catalog_info (readOnlyHint) via the modelContext mount.
